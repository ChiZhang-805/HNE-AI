# 两侧共享的实验接口

本合同规定两侧应共同验收的目标接口。已有实现需逐项核验；本次目录交付不代表新增训练实现已同步或全部字段已经实现。历史文件通过适配器接入，不改写旧记录。

## 固定任务与来源

主终点和日历由`configs/daily_protocol.json`定义，SHA-256为`3d58b3089a3e7d25a442ec8aa78638c509fc03fcf2af901e1cfbe2b5ab17607c`。日末d发报，d+1为空档，预测d+2至d+8；个人参考56日、L历史32日、小模型28日上下文生成最近14日证据。H/N/E表示个人历史、状态指标关系、已观测情境，参考期不等于经临床确认的健康期。

外层评估折k，验证折(k+1)%5，其余三折训练；两库、5折、3种子沿用配置。两个人体库已有开发暴露。空气质量目标验证/测试结局在框架和选择规则锁定前不进入开发。公开预训练权重与原第一篇输入只读。

`HNE_STUDY_ROOT`指向第二篇的独立输入根目录，默认本项目。新读取入口统一使用`src/study_inputs.py`，不回退到第一篇目录。交接包通过私有渠道提供，并按[交接说明](private_handoff.md)校验。历史manifest中的第一篇路径保留作来源记录；校验时按相对数据路径和hash匹配当前副本，不访问第一篇。

## 教师与证据：A生产，B核验及消费

当前接口由`src/train_evidence.py::origin_evidence`和`src/fusion/evidence.py`定义。交付时应核验的证据张量约定为：节点`[6,21,9]`、节点有效性`[6,21]`、有向边`[21,6,6,4]`、边有效性`[21,6,6]`；额外有原始误差、12维质量摘要及来源角色/族信息。具体键名与方向以当前函数返回值为准，接入检查必须打印并校验结构，不能靠本文的语义名猜键名。

21个历史patch及其age只取发报时刻之前的信息。节点误差含H/HN/HNE损失、残差及条件增益变化；不得把缺测当零观测。N/E关系是预测关系，不能解释为生理因果。完整末端融合可以保留质量摘要；比较内部同证据时还需报告node/edge-only控制，说明额外摘要的差别。

教师交付收据至少含：固定协议hash、训练/内层选型人员排除摘要、S检查点hash、输入数据hash、个人拟合/分数校准时间段、证据键/shape/dtype、数值变换及mask定义、代码提交、配置hash。具体人员清单和校准张量放私有包，公开收据只保留验证通过状态与摘要计数。

B的普通统计、结构、检索和错配控制必须提供同一运行键上的替代证据或方法适配器。不得将目标结局用于选择邻居；不得改写A的S证据缓存。不存在有效源时的处理和显式关闭语义必须写清。

## 共同大模型和注入：A生产，双方共用

M04是共同无指导锚点。同一外层折/种子的M10/M12/M13及其他依赖对照引用相同M04检查点；需要重新训练锚点的特殊设置（如recent-only）另登记成对锚点，不能偷偷替换。

内部指导接口通过`pack_bias`与Chronos后四层attention接口接入；完整输入残差经过所有原生block，不能复用旧输入下的前缀hidden作为其训练前向。L与事件头在指导/融合阶段冻结，梯度可穿过冻结骨干回传到输入残差。显式关闭恢复M04；有效证据的数值为零不等于关闭。M02证据独立头的epoch0不是M04回退，不能套用残差分支的“关闭”含义。

源验证NLL选型；正式残差最少训练6轮，但第1轮起的检查点均参加选型，另含epoch0无干预候选。分别保存always-on和selected结果。旧的 scripts/run_key_comparison.py 入口仍是一个预设学习率。新的 experiments/core/run.py 已实现M10与M12各六候选（3个学习率×2个weight decay）、共同M04及node/edge-only控制，并保存selected和always-on；当前配置仅为单源折开发检查，全折和其余方法编排仍待完成。实际完成状态见 experiments/core/runs/matched_guidance.json，不能把代码存在当作运行完成。

## 方法输出：共同的可评估预测记录

新适配器应输出以下字段。现有CSV缺少的字段由来源manifest补齐并生成旁路标准化记录，不覆盖原文件，也不编造缺失来源。

| 字段 | 约束 |
| --- | --- |
| dataset, person, origin, issue_time | 共同起点键；person和逐行记录留私有包；同方法同策略每键唯一 |
| evaluation_fold, validation_fold, seed, method_id | 使用统一登记的折、种子和M01–M13或公共算法名 |
| policy | `always_off`、`always_on`、`selected`或明确的gate策略，禁止混合汇总 |
| probability | 有限且在[0,1]；非概率分数的链接函数必须显式记录 |
| label | 0/1或未知；仅评价器读取；未知日期仍参与报警和静默状态 |
| max_input_time, target_start, target_end, label_mature_time | 输入止于发报；监督只能用当时已成熟的训练结局 |
| protocol_hash, config_hash, code_commit | 不同配置不得共用一个完成标记 |
| base_checkpoint_hash, teacher_checkpoint_hash, evidence_hash | 不适用时显式写null；禁止用空字符串掩盖缺失交付 |
| selected_epoch, checkpoint_policy | 区分训练轮数、epoch0评价和实际选择；保留未选中的负结果 |

运行键是`study/dataset/fold/seed/method/config_digest`。认领收据只含这个键、owner、状态、代码提交和公开可接受的计数/时间。**Git记录不是分布式锁**：认领应先推送并确认远端没有同键认领；发现冲突先协调唯一执行者，不同时启动两份。

## 独立评分：B生产，A核验

- AUROC按外层折n+×n−加权；各种子先评分再平均，不把平均概率变成未经声明的集成。
- 人员内部AUROC仅比较同一人的正负日期，再按配对数加权；报告可计算人数和单类人员。AUPRC、NLL、Brier及固定0.5阈值的准确率/敏感度按原实验矩阵执行。
- 2,000次折内人员配对bootstrap，所有时序/方法/种子随同一人重采样；固定模型区间不包含完整重训练不确定性。正式主要对比采用运行前登记的Holm家族；开发诊断不冒充确认性检验。
- 阈值只在源验证集选定；主误报预算分母是可评分起报人日。所有历史合格日参与回放，未知报警触发7日静默。当前操作性提前量固定一天；长gap与合成变点分别回答预测距离和机制提前量。
- 输出总数、阳性人数、未知结局数、覆盖/校准、配对差值及全部种子；任何单类或失败条件保留NA和原因。

## 门控、迁移和结果验收

Gate目标是成熟结局上的`BCE_off - BCE_on`。用于构造某人的OOF预测时，S、LoRA、事件头、G及其选型都必须排除该人；仅对S做交叉拟合不够。A交付排除审计，B在评分前验证。原pilot的样本内L缓存不能充当合法gate训练集。

T0冻结共享权重和阈值；T1只按已声明的无标签个人参考重学当地规律；T2/T3的目标监督标签预算单独记账。B的冻结推理/扰动结果引用A的已锁定源检查点，不能同时微调后继续称冻结迁移。

每项交付必须包含：运行收据、完整配置和来源、私有逐起点预测位置、可公开汇总、与共享锚点的一致性检查、真实成本、失败/中断记录和结论边界。A核对机制与训练条件，B核对数据/统计/图表；双方均不能通过改终点、删人员、只留最好种子补出正结果。
